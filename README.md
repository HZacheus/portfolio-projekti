# Portfolio-projekti

## Projektin tarkoitus: Tämän projektin tarkoituksena on toimia henkilökohtaisena portfoliona, jossa esittelen osaamistani ja kurssin aikana tehtyjä projekteja.

## Sivu on tarkoitettu opettajalle, mahdollisille työnantajille sekä muille, jotka ovat kiinnostuneita osaamisestani.

## Käytettävät teknologiat - HTML - CSS - JavaScript - Git - GitHub
